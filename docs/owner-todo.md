## 1. Google Drive を繋ぐ（残りは Google Cloud Console の1行だけ）

**認証情報はもう本番に入っています**（8/31 に保存されているのを確認しました）。
設定画面での作業は済んでいるので、ここは消しました。

**残っているのは Google 側の登録だけです。** こちらから Google に問い合わせたところ、
**リダイレクト URI が1つも登録されていません**——本番の URL でも `localhost` でも
`redirect_uri_mismatch` が返ります。この状態で「接続」を押すと、Google の
**エラー 400 の画面**が出て戻ってきます（アプリ側は正常です）。

- [ ] **[Google Cloud Console → 認証情報](https://console.cloud.google.com/apis/credentials)**
      → OAuth 2.0 クライアント ID の **`503294955762-qg68k...`** を開く
      → **「承認済みのリダイレクト URI」**に**この2つ**を追加して保存:
      - `https://rsstube.vercel.app/api/auth/google/callback` （本番。これが本命）
      - `http://localhost:3000/api/auth/google/callback` （手元で私が試すぶん）
- [ ] **[本番の設定画面](https://rsstube.vercel.app/settings) → Google Drive →
      「Google Drive に接続」を押す**

**「承認済みのリダイレクト URI」の欄が見当たらないときは、クライアントの種類が
「ウェブ アプリケーション」以外**（デスクトップアプリなど）です。その場合は
「＋認証情報を作成 → OAuth クライアント ID → ウェブ アプリケーション」で作り直し、
新しい ID とシークレットを
[設定画面](https://rsstube.vercel.app/settings?drive=unconfigured)の
「Google の認証情報」に入れ直してください。

反映に数分かかることがあります。押していただければ、実際にファイルが置けるところまで
私が確認します。**OAuth クライアントはアプリに1つで足ります**——2人目からは
接続ボタンを押すだけです。
