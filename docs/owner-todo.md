## 3. 音声について決めてほしいこと

- [ ] **話し方を選ぶ** — 設定画面の「アプリ内音声の作り」で、
      **2人の対話**か**1人の語り**か。次に作るものから効きます
- [ ] **声を選ぶ** — `samples/voices/` に6種類の声で同じニュース原稿を読ませたものがあります
      （`npm run voices` で作り直せます）。気に入ったものを `.env.local` の
      `GEMINI_TTS_VOICE_A`（1人語りと対話の進行役）/ `_B`（聞き手）に入れてください。
      **本番の Vercel にも同じ値を入れること**
- [ ] **保存期間** — サーバー上の音声は30日で消えます。いま使っているのは
      無料枠1GBのうち 5.2MB だけなので、伸ばす余裕はあります。日数は設定画面から変えられます

### Google Cloud TTS に移るときは、あなたの作業が要ります

Gemini TTS は preview なので、いつ無料枠が変わってもおかしくありません。
移り先は Google Cloud TTS（無料枠400万文字/月）ですが、**APIキーでは叩けません**
（手元の `GEMINI_API_KEY` で試すと 401 で「API keys are not supported by this API」）。
GCPプロジェクトで Cloud Text-to-Speech API を有効にし、サービスアカウントの鍵を
発行して Vercel に入れる必要があります。**いま急ぐ必要はありません。**
