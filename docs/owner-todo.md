- [ ] **話し方を選ぶ** — 設定画面の「アプリ内音声の作り」で、

      `GEMINI_TTS_VOICE_A`（1人語りと対話の進行役）/ `_B`（聞き手）に入れてください。
      **本番の Vercel にも同じ値を入れること**
- [ ] **保存期間** — サーバー上の音声は30日で消えます。いま使っているのは
      無料枠1GBのうち 5.2MB だけなので、伸ばす余裕はあります。日数は設定画面から変えられます

### Google Cloud TTS に移るときは、あなたの作業が要ります

Gemini TTS は preview なので、いつ無料枠が変わってもおかしくありません。
移り先は Google Cloud TTS（無料枠400万文字/月）ですが、**APIキーでは叩けません**
（手元の `GEMINI_API_KEY` で試すと 401 で「API keys are not supported by this API」）。
GCPプロジェクトで Cloud Text-to-Speech API を有効にし、サービスアカウントの鍵を
発行して Vercel に入れる必要があります。**いま急ぐ必要はありません。**

## 7. 決めてほしいこと（8/26 追加）— RSS の無いページをどうするか

`回復術士のやり直し` のように、**サイトがRSSをやめてしまった**ページがあります。
「更新があったことが分かればいい」というご要望に対して、10ページで実測しました。

- **本文テキストのハッシュを比べる方法は使えます。** 10ページ中10ページで
  ハッシュが安定し（3秒あけて2回取って変化なし）、8ページで
  「フィードの最新記事の題」がページ本文に出ていました＝更新で必ず変わります
- **生HTMLのハッシュは使えません。** 4ページ中2ページが3秒で変わりました（広告枠）
- **登録するURLの選定がすべてです。** ComicWalker は素のURLだと「第1話」が出たままで
  **新話が出ても変わりません**。`?episodeType=latest` を付けると最新話が出ます
- **どのURLが良いかを自動で判定する方法は見つかりませんでした。**
  「最近の日付が本文にあるか」で判定を書いたら11件中3件を間違え、しかも
  「絶対に鳴らないURL」を合格と判定しました

なので **「最初の数日は記録だけして、実際に何回変わったかを見てから通知に昇格させる」**
形を提案しています。作ってよければ、まず ComicWalker の
`?episodeType=latest` 1本で試します（次の更新は9月上旬の見込み）。
