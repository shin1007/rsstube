## 3. 音声について決めてほしいこと

夜のうちに、選べるようにしたものと、選ぶための材料を用意しました。

- [ ] **話し方を選ぶ** — 設定画面に「アプリ内音声の作り」を足しました。
      **2人の対話**（いままで）か**1人の語り**か。次に作るものから効きます
- [ ] **声を選ぶ** — `samples/voices/` に6種類の声で同じニュース原稿を読ませたものがあります
      （`npm run voices` で作り直せます）。気に入ったものを `.env.local` の
      `GEMINI_TTS_VOICE_A`（1人語りと対話の進行役）/ `_B`（聞き手）に入れてください。
      **本番の Vercel にも同じ値を入れること**
- [ ] **保存期間** — サーバー上の音声は30日で消えます（Storage の無料枠1GB、実測473KB/分）。
      残したいものは「聴く」か再生画面の「保存」から MP3 で落とせます。
      日数は設定画面から変えられます

### Google Cloud TTS に移るときは、あなたの作業が要ります

Gemini TTS は preview なので、いつ無料枠が変わってもおかしくありません。
移り先は Google Cloud TTS（無料枠400万文字/月）ですが、**APIキーでは叩けません**。
手元の `GEMINI_API_KEY` で試したところ 401 で、
「API keys are not supported by this API」と返ります。

移るときは、GCPプロジェクトで Cloud Text-to-Speech API を有効にし、
サービスアカウントの鍵を発行して Vercel に入れる必要があります。
**いま急ぐ必要はありません**（Gemini TTS が動いているうちは）。
