## 1. いますぐ（スマホで使えない・穴が開いている）

### 1-1. Supabase の URL 設定を直す ← スマホのログインが通らない原因

マジックリンクが `localhost` に飛ぶのはこれです。アプリは正しく本番のURLを渡して
いますが、**Supabase 側の許可リストに無いURLは Site URL に読み替えられます**。

`https://supabase.com/dashboard/project/nrbykrzkwntbcbcwumew/auth/url-configuration`

1. **Site URL** を `https://rsstube.vercel.app` に変更
2. **Redirect URLs** に追加
   - `https://rsstube.vercel.app/**`
   - `http://localhost:3000/**` ← 消さないこと（手元の開発でログインできなくなる）

### 1-2. 新規サインアップを止める ← 誰でもアカウントを作れる状態

`disable_signup: false` を確認しました。**「Allow new users to sign up」がオンです。**

publishable key はクライアントに配る前提の公開鍵なので、誰でも取得できます。それで
`auth/v1/signup` を直接叩けば `ALLOWED_EMAILS` を素通りしてアカウントが作れます。
記事・要約・フィードは全ユーザー共通なので、入られると購読しているURLの一覧まで見えます。

Authentication → Sign In / Providers → Email →
**「Allow new users to sign up」をオフ**

（1-1 と同じ画面のすぐ近くなので、まとめてどうぞ）

**終わったら教えてください。** 実際に塞がったか、存在しないアドレスで `signup` を
叩いて確かめます。
