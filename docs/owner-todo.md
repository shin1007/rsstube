## 1. Google Drive を繋ぐ（本番の設定画面で、5分）

繋がらなかったのは同意がまだだからではなく、**本番に認証情報が入っていなかった**から。
ご指摘のとおり Vercel の環境変数は触れる人が限られるので、**設定画面から入れられるように
変えました**（`0033`）。Vercel を触る必要はもうありません。

- [ ] **[本番の設定画面](https://rsstube.vercel.app/settings?drive=unconfigured) →
      Google Drive →「Google の認証情報」**に、`.env.local` と同じ
      **クライアント ID とシークレット**を入れて保存（手元の値をそのまま使えます。
      Google Cloud Console から取り直す必要はありません）
- [ ] **[Google Cloud Console](https://console.cloud.google.com/apis/library) → 認証情報 →
      OAuth クライアント →「承認済みのリダイレクト URI」**に
      `https://rsstube.vercel.app/api/auth/google/callback` を追加（localhost のぶんは残したまま。
      **登録すべき文字列は設定画面にそのまま出しています**）
      - 認証情報の画面には
        <https://console.cloud.google.com/apis/credentials> で直接飛べます
- [ ] **「Google Drive に接続」を押す**

押していただければ、実際にファイルが置けるところまで私が確認します。
**OAuth クライアントはアプリに1つで足ります**——2人目からは接続ボタンを押すだけです。

## 6. これから私が作るもの（作業は不要。方針の確認だけ）

**RSS の無いページの監視。** 決まったことは「**更新があったことだけを知らせる**」。
中身は取りに行きません（RSS が無いページから本文を組み立てようとすると、広告や目次を
本文として掴んで、要約まで巻き添えになる）。出しかたは**普通の記事と同じ形**にして、
一覧に1行増やします——「RSS が無いので中身は取れていません。更新があったことだけ
お知らせします」と記事の中身として書く形です。スター・あとで・既読がそのまま使えます。

実測の詳細（本文ハッシュは安定・生HTMLは3秒で変わる・URL選定がすべて）は
`docs/status.md` の見送り判断のところに残してあります。
