# 音声・スライド生成の選択肢

いま使っているのは Gemini TTS と自前のスライド描画。他に何があって、どういうときに
乗り換えるのかを残しておく。**乗り換えるべき理由が出てくるまでは今のままでよい**、
というのが結論。

調べた時点: 2026-08-14

---

## いまの構成

| 役割 | 使っているもの | 費用 |
|---|---|---|
| 台本 | `gemini-3.5-flash` | 無料枠（1日20回） |
| 音声 | `gemini-3.1-flash-tts-preview`（2話者） | 無料枠（preview のあいだ） |
| スライド | 自前（スライドJSON → HTML/CSS） | 0 |
| 配信 | Supabase Storage（署名付きURL） | 無料枠1GB |

**選んだ理由**: 2話者の対話をそのまま1リクエストで作れる TTS が他にほぼ無い。
台本と同じ API・同じキーで済み、無料枠の中で完結する。

**弱点**: preview なので予告なく仕様や無料枠が変わり得る。声の種類は
プリセットのみ（クローンなし）。品質は ElevenLabs には及ばない。

---

## 音声の代替

| サービス | 無料枠 | 有料 | 2話者 | 日本語 | 乗り換える理由になるとき |
|---|---|---|---|---|---|
| **Gemini TTS**（現行） | preview 中は無料 | — | ○（1回で完結） | ○ | — |
| **Google Cloud TTS** | 400万文字/月 | WaveNet $4/100万文字 | ×（話者ごとに呼ぶ） | ○ | Gemini の preview が終わったとき。無料枠は桁違いに大きい |
| **OpenAI TTS** | なし（$200 クレジット） | $15/100万文字 | × | ○ | 品質と安定性を優先したいとき |
| **ElevenLabs** | 1万文字/月（10〜15分ぶん） | $0.30/1000文字 | × | ○ | 声の質を最優先にするとき。**毎朝10分だと無料枠に入らない** |
| **VOICEVOX / AivisSpeech** | 完全無料（ローカル） | 0 | ○（話者を変えて合成） | ◎ | 費用をゼロに固定したいとき。**ただしサーバーが要る**（Vercel では動かない） |

### 現実的な次の一手は Google Cloud TTS

Gemini TTS の preview が終わったら、ここが本命。無料枠400万文字/月は、毎朝10分
（約3000文字）を毎日作っても**月9万文字**なので、桁が2つ余る。

ただし**2話者を1回で作れない**ので、発話ごとに話者を切り替えて呼び、こちらで
つなぐ必要がある。いまの設計はセグメント単位で音声を持っているので、
「セグメント内をさらに発話単位で合成して連結する」形にすれば
`lib/ai/tts.ts` の差し替えだけで済む（呼び出し回数は増える）。

### VOICEVOX は構成が変わる

品質と費用は魅力的だが、ローカルで動かす前提のソフトなので、Vercel の
サーバーレス関数からは呼べない。常時動くサーバーを1つ持つ覚悟が要る。
「費用をゼロに固定したい」以外の理由では選ばない。

---

## スライド・動画の代替

### NotebookLM（Gemini Notebook）は選択肢が増えた

2026年7月に「Gemini Notebook」へ改称。**Audio Overview に加えて、Video Overview
（ナレーション付きスライド）、Slide Deck、Infographic、Mind Map** などが出せるようになった。
標準の Video Overview は無料でも**1日3本**まで。

**ただし API は相変わらず一般提供されていない。** Enterprise 向けの Notebook API は
プレビューにあるが組織契約が前提で、コンシューマ版のキーは配られていない。
つまり「アプリから自動で作る」はできず、これまでどおり
**アプリで整形 → 人が投入**の形しか取れない。

`/exports` の書き出しはそのために残してある。**手で開く手間を許容できるなら、
出来上がりは NotebookLM のほうが上**というのは今も変わらない。

### mp4 は作らない（判断は変えない）

スライドJSONを HTML/CSS で描く方式のままにする。理由は plan.md の §4 のとおりで、
実装してみて追加で分かったこともある:

- サーバー側の動画合成が要らない（無料枠に収まる最大の理由）
- 文字が選択でき、画面幅で折り返る。スマホでそのまま読める
- **音声をセグメントに割ったので、スライドとの同期に計算が要らない**
  （クリップの切れ目＝スライドの切り替わり）
- 途中スライドへのジャンプが、単にクリップの切り替えで済む

mp4 が必要になったら（SNS に上げたい、など）、同じスライドJSONとセグメント音声を
材料に外部ワーカーで合成できる。いまの実装がそのまま素材になる。

---

## まとめ

- **いまは変えない。** 2話者を1回で作れて無料枠に収まるのは Gemini TTS だけ。
- **preview が終わったら Google Cloud TTS**。`lib/ai/tts.ts` の差し替えで済む形にしてある。
- **NotebookLM は API が無い以上、自動化の対象にはならない。**
  ただし出来上がりは上なので、書き出しの経路は残し続ける。
- **mp4 は作らない。** セグメント音声＋スライドJSONという素材の持ち方は、
  後から動画にする道も塞いでいない。
